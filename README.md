## 🌍 Desteklenen Diller / Supported Languages (10 Languages)
TR, EN, FR, ES, PT, ID, RU, ZH, AR (RTL) ve UR (RTL) dillerini destekler.

## ✨ Özellikler / Features
Namaz Vakitleri, Hicri/Miladi Takvim, 114 Suresi ve Tilavetiyle Kur'an-ı Kerim, Sahih-i Buhârî Hadis Arşivi, Dini Günler, Namaz Rehberi, Dijital Tesbihat ve Tam Kişiselleştirme seçenekleri sunar.

## 📦 Kurulum / Installation
Evrensel kurulum veya Debian/Ubuntu (`.deb`) paketleri üzerinden kurulabilir. Ayrıntılı kurulum, gereksinimler ve lisans bilgileri için tam dosya içeriğine repodaki `README.md` üzerinden ulaşabilirsiniz.
