# Sirat

A lightweight, fast, and modern **Islamic Companion** built for all major Linux distributions with automatic Light/Dark theme and OS language detection.

## Features
- **Prayer Times:** Automatic location detection, city/country selection, offline astronomical calculation (Diyanet method), and live countdown timer.
- **Holy Quran & Audio:** Complete 114 Surahs offline (Arabic Uthmani text + Turkish & English translations) with built-in audio player featuring 9 renowned reciters (Alafasy, Al-Sudais, Islam Sobhi, Al-Muaiqly, Al-Dosari, Al-Qatami, Al-Ghamdi, Al-Minshawi, Abdul Basit).
- **Hadith Collection:** Complete Sahih al-Bukhari (97 books, 7,500+ Hadiths) in Turkish and English with instant keyword search and pagination.
- **Islamic Days & Worship Guide:** Calendar of all holy nights and Eid days with countdowns and recommended acts of worship.
- **Prayer, Wudu & Dhikr Guide:** Illustrated prayer postures (separately for Men and Women), step-by-step Wudu, Jumu'ah & Eid prayers, essential Duas, and daily Dhikr.
- **Multilingual & Adaptive:** Automatic OS language (`TR`/`EN`), Light/Dark/Auto theme switching, dynamic font sizing (`A-`/`A+`), and multilingual About section.

## Installation

### Option 1: Debian / Ubuntu / CutefishOS (`.deb` Package)
Download `sirat_1.0.0_all.deb` from the [Releases](https://github.com) page and install:
```bash
sudo apt install ./sirat_1.0.0_all.deb
```

### Option 2: Universal Linux Installer (Ubuntu, Fedora, Arch, Mint)
```bash
git clone https://github.com
cd sirat
bash install.sh
```
